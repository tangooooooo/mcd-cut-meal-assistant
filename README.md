# 麦当劳减脂选餐助手

基于麦当劳 MCP 餐品营养信息的单页选餐工具。用户填写基础身体信息和日常活动情况后，工具估算基础代谢、每日总能量消耗（TDEE）与温和减脂热量目标，并根据当前时间或手动选择的餐次，推荐“主食 + 小食 + 饮品”组合。

## 项目状态

当前为可本地运行的前端原型 / MVP，代码集中在 `index.html`，无需安装依赖或启动后端。部分餐品数据已从麦当劳 MCP 返回结果整理为页面内的参考数据；本地运行时不会自动连接 MCP 实时刷新数据。

## 目标用户

- 想在减脂期间选择麦当劳餐品的成年人
- 希望获得简单热量参考和餐次搭配建议的用户
- 对热量记录有一定经验、需要快速比较餐品的人

## 功能

- 逐题填写性别、年龄、身高、当前体重、目标体重、目标日期、工作活动量、日均步数、训练频率与训练类型
- 在浏览器本地保存资料，并可返回修改
- 使用 Mifflin–St Jeor 公式估算基础代谢，并结合活动量近似估算 TDEE
- 给出温和减脂的每日能量建议，并提示目标期限对应的缺口可能过大
- 按本地时间建议早餐、午餐、晚餐或加餐；用户可手动切换餐次、修改当餐热量目标
- 推荐主食、小食、饮品组合，支持换一组、替换单品，也可浏览并自由选择餐品
- 通过友善的角色提示提醒餐量过低、过高或计划缺口过大

## 使用方法

1. 下载或克隆本项目。
2. 在浏览器中打开 `index.html`。
3. 按页面提示完成资料录入；资料仅保存在当前浏览器的 `localStorage` 中。
4. 查看当餐建议组合；可切换餐次、修改热量目标、换一组或自行选择单品。

无需 Node.js、数据库、API 密钥或构建步骤。建议使用最新版 Chrome、Edge、Safari 或 Firefox。

## MCP 集成说明

请见 [MCP_INTEGRATION.md](MCP_INTEGRATION.md)。当前提交版本包含依据麦当劳 MCP 返回营养信息整理的静态参考餐品数据，不在浏览器中直接保存或调用 MCP Token。

## 数据、隐私与健康提示

- 身体资料存储于本机浏览器 `localStorage`，清除浏览器站点数据会删除资料；当前版本没有账号、云端同步或服务器上传。
- 热量及营养数据仅供参考；地区、菜单、份量与供应状态可能变化，以麦当劳官方渠道为准。
- TDEE 是估算值，不是测量结果；实际能量需求因个体情况而异。
- 工具输出不构成医疗、营养或其他专业建议。对饮食或健康有疑问时，请咨询合格专业人士。
- 本项目为参赛者独立开发的创意作品，并非麦当劳官方产品。
